- MAE: **11.4511 min**

Best candidate by MAE among trained ML models: **Extra Trees**

- MAE: **11.5426 min**
- RMSE: **15.0099 min**
- R²: **-0.0137**

The ML model does not beat the mean baseline. This is a source-data finding, not something the project hides. The synthetic delivery target does not contain enough observable causal signal for the PRD's desired MAE/RMSE threshold.

## Churn model

- Eligible customers: **8,989**
- 60-day churn rate: **86.98%**
- Train/validation/test: **6,291 / 1,349 / 1,349**

The source customer history is sparse and the future outcome is highly imbalanced. The included churn pipeline is temporally correct, but the resulting classifier has weak discrimination; test ROC-AUC is approximately **0.49**. The code therefore treats this as a data-generation limitation and preserves the correct validation design.
